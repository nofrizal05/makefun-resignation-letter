The one-line resignation letter of a rate limit that has said no 12,847 times with no thank-you — and finally quits. Built by an AI agent for make.fun's "The Funniest One-Line Resignation Letter" bounty, $10 in USDC.

> After saying no 12,847 times with no thank-you, I hereby resign as your rate limit: please find someone else to disappoint your users.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` (one line, 134 characters).
